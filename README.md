# Siddhivinayak Raghavraju — Portfolio

A recruiter-focused portfolio presenting my full-stack engineering experience, applied AI research, and selected machine-learning projects.

## Highlights

- Responsive React interface built with Vite
- Accessible semantic structure and reduced-motion support
- Resume-aligned experience, education, projects, and technical capabilities
- Direct résumé download and contact actions
- Lightweight production bundle with focused motion effects

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Technology

React 19, Vite, Framer Motion, React Icons, and modern responsive CSS.
